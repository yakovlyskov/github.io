# Growth Mission · игра на GitHub Pages

[Открыть игру](https://yakovlyskov.github.io/github.io/growth-mission/) · [Самостоятельный урок](https://yakovlyskov.github.io/github.io/growth-lab/)

Вход больше не перенаправляет участников на chatgpt.site. Интерфейс и все игровые материалы загружаются непосредственно с GitHub Pages. Совместная сессия работает через WebRTC и PeerJS Cloud; отдельного аккаунта не требуется. Камера и микрофон игре не нужны.

## Провести встречу в Zoom

1. Откройте игру, нажмите «Я ведущий» → «Создать комнату».
2. Нажмите «Пригласить», отправьте ссылку участникам в чате Zoom. Код новой комнаты содержит 12 символов.
3. Держите вкладку ведущего открытой. Участники выбирают имя, ведущий видит список подключившихся.
4. Откройте раунд. Ведущий видит сохранённые черновики и отправленные ответы. Затем закройте ответы, откройте общий разбор и перейдите дальше.
5. Выбор оценивается автоматически; письменные и практические ответы ведущий оценивает по критериям после разбора. Баллов за скорость нет.
6. Скачайте CSV/JSON со статистикой и «Резервную копию» комнаты. «Экран Zoom» скрывает частные ответы и шпаргалку ведущего.

14 раундов, пять актов, до 140 очков. Ориентир — 75–90 минут плюс работа в АБ-платформе, часть которой можно вынести между встречами. Все работают с одним общим экспериментом на уведомлённых сотрудниках, чтобы не создавать пересечения КУСов. Дежурный выполняет действие, остальные проверяют его и фиксируют свою роль или блокер.

## Где хранятся ответы

В новой версии единственный источник состояния — браузер ведущего. Он проверяет права, время раунда и приём ответов, сохраняет данные перед подтверждением участнику. Участники получают свои ответы; чужие черновики им не передаются. До разбора интерфейс скрывает правильный ответ и начисленные баллы. Учебная колода входит в клиентский код и доступна в публичных исходниках: это обучающая игра, не защищённый экзамен.

Состояние автоматически сохраняется в localStorage ведущего. Если он закрыл вкладку, связь участников приостанавливается; после возвращения в комнату с того же браузера они переподключаются. Не очищайте данные сайта до выгрузки. Для переноса на другое устройство скачайте резервную копию, закройте прежнюю вкладку и загрузите файл через «Восстановить комнату ведущего из файла» на главной. Обычный CSV/JSON со статистикой не является резервной копией.

Резервная копия содержит ключ управления комнатой и ответы. Храните её у ведущего и не рассылайте как приглашение. Участник может сохранить «Мой ключ» и «Мои материалы». Соединения WebRTC шифруются; ответы ведущего подписываются ECDSA, его открытый ключ связан с кодом комнаты. Защищённое хранилище для реальных клиентских данных эта игра не заменяет. КУСы и рабочие логи в игру не вводите.

PeerJS Cloud помогает браузерам установить соединение; возможна передача через его TURN-реле. Это внешний общедоступный сервис без нашего SLA. До встречи проверьте подключение одного участника из вашей рабочей сети. Если сеть запрещает PeerJS/WebRTC, приложение покажет ошибку соединения — потребуется разрешённая сеть либо отдельное размещение серверной версии. Блокировка chatgpt.site для новой версии не имеет значения.

## Старые комнаты

Серверные комнаты с 6-значными кодами не перенесены в браузерную версию. Создайте новую комнату. Прежняя серверная публикация сохранена, её данные не удалены; её исходники остаются в [source.zip](./source.zip) и каталоге [src](./src). Доступ к ней зависит от доступности домена прежнего хостинга.

## Источник кейса

[Инструкция АБ-платформы 2.3 от 23.10.2026](https://docs.google.com/document/d/1F-udK7dMbjDO7lCcZXdV384FEN7NlGP-18EptZSvYLY/edit?tab=t.0). Кейс и статистика вымышлены. Правила и неподтверждённые места инструкции сохранены в 14 раундах, подробный маршрут — в самостоятельном уроке. Игра не подключена к банковской платформе: артефакты и выполнение практики подтверждаются вручную.

## Исходники и сборка

Текущая браузерная версия: [browser-src](./browser-src), [архив](./github-pages-source.zip).

```sh
npm ci
npm test
npm run build
```

Публикуйте содержимое `dist` как `growth-mission/` в GitHub Pages. Для локального тестирования соединений нужен HTTPS либо localhost: Web Crypto не работает на произвольном HTTP-адресе.

Зависимости зафиксированы в package-lock.json. Использованы React, Lucide и PeerJS; лицензии в THIRD-PARTY-NOTICES.txt. Автоматическая проверка: 10 участников, все 14 раундов, 140 отправок; права ролей, таймер, скрытие разбора, заморозка ответов, оценки, блокеры, сохранение и продолжение, откат при ошибке сохранения, отсутствие ключей в экспорте. Это проверка логики, а не нагрузочный тест 10 отдельных браузеров.
